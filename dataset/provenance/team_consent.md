# Provenance: team recordings (`team_s1`, `team_s2`, `team_s3`)

These sources have no external page to capture, because the recordings are our
own. Their right to publish comes from written consent, not from a licence
statement on a web page.

- **Licence:** CC BY 4.0, as stated in `SOURCES.yaml` for each `team_*` source.
- **Evidence:** [`../CONSENT.md`](../CONSENT.md) — one signed line per person,
  naming them as credited, with the date.
- **Texts:** public domain in their own right (an 1863 speech, and US federal
  works), so reading them aloud creates no third-party right.
- **Recording protocol:** [`../audio/raw/team/README.md`](../audio/raw/team/README.md).

`scripts/check_provenance.py` resolves this file through each `team_*` source's
`provenance:` field, so a bronze-tier file passes the provenance check only while
this file and `CONSENT.md` both exist.

**Status 2026-10-05:** no team recordings have been made and no one has signed
`CONSENT.md`. This file is the placeholder the sources point at; it becomes
meaningful evidence only once that table is filled in.
