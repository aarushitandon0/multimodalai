# Dataset build pipeline

These scripts build the contrastive dataset. `make data` runs them in order;
each is idempotent and writes only under `dataset/` and `.cache/`.

| Order | Script | Does | Writes |
|---|---|---|---|
| 1 | `download_sources.py` | Download public-domain sources after the licence gate | `dataset/audio/raw/`, `dataset/LICENSES.csv` |
| 1b | `check_provenance.py` | Fail if any audio lacks a licence row or saved licence statement | — (exit code) |
| 2 | `build_clean.py` | 16 kHz mono, excerpt, 300 ms lead/tail, −23 LUFS, peak ≤ −1 dBFS, hash | `dataset/audio/clean/`, `MANIFEST.csv`, `qc/clean_build.csv` |
| 3 | `align_clean.py` | `conda run -n mfa mfa validate` then `mfa align`, in one batch | `dataset/alignments/*.TextGrid` |
| 3b | `align_report.py` | Per-file alignment QC; flags files over the unaligned-word budget | `dataset/qc/align_report.csv` |
| 4 | `build_injected.py` | Severity ladder L1–L4 per label + 4 composites, with exact time maps; labels and events come from those maps | `dataset/audio/injected/`, `dataset/labels/*.json`, `labels/events.tsv`, `dataset/alignments/<id>.json`, `qc/rejections.csv` |
| 5 | `qc.py` (TODO) | Re-align (reject > 50 ms boundary error), UTMOS drop gates | QC report; drops failing files; fills each label's `qc` block |
| 6a | `annotate_prepare.py` | Align human takes, append an empty `flaws` tier, hand each file to its annotator(s) | `dataset/annotation/todo/<annotator>/*.TextGrid`, `annotation/assignments.csv`, `dataset/alignments/*.TextGrid` |
| 6b | `annotate_import.py` | Validate completed Praat flaw tiers against the taxonomy → labels (`origin: human`, `split: test`) | `dataset/labels/*.json`, `labels/events.tsv`, `dataset/alignments/*.TextGrid`, `MANIFEST.csv` |
| 6c | `annotator_agreement.py` | Event-F1 @ 200 ms onset collar + Cohen's κ between two annotators | `dataset/qc/agreement.md`, `qc/agreement.json` |
| 7 | `make_splits.py` (TODO) | Leave-one-text-out folds and checksums | `dataset/splits/`, `dataset/checksums.sha256` |

`build_injected.py` needs gap labels (`boundary` / `minor` / `none`), which come
from the display transcript's punctuation via `rostrum.text` (spec 7.1). MFA
leaves every gap at `none`, so until that module exists `missing_pause`,
`low_energy`, `monotone` and `misplaced_stress` have no valid span and are
logged in `qc/rejections.csv` rather than guessed at.

## Rules these scripts must honour

- **A licence row before a download.** No file enters `dataset/` without a row
  in `LICENSES.csv` carrying its source URL, licence and retrieval date. Only
  public-domain / CC0 / CC BY sources, or consented team recordings.
- **Edits at word boundaries only**, taken from the forced alignment of the
  clean file, with 10 ms raised-cosine crossfades at zero crossings.
- **Inserted silence is looped room tone**, sampled from the recording's own
  pauses. Digital zeros are an artefact a detector can cheat on.
- **Every op returns an exact old → new time map.** Later timestamps are
  recomputed from the cumulative offset, never re-estimated.
- **Labels come from the time maps, then are verified** by re-alignment. A file
  whose word boundaries moved more than 50 ms is dropped, not corrected.
- **Quality over quantity.** A file that fails a QC gate is deleted. A smaller,
  cleanly aligned contrastive spectrum beats a large noisy corpus.
- **Deterministic.** Every script takes its seed from `configs/injection.yaml`
  and records the resolved seed and parameters in the label JSON, so any file
  can be regenerated byte-for-byte.
- **`mumbling` is never synthesised** — it comes only from human recordings.
- **An annotation is rejected, never repaired.** `annotate_import.py` skips any
  file whose `flaws` tier holds an interval outside
  `<label>:<severity 1-3>`; a label coerced into something plausible becomes
  wrong ground truth that every metric is then measured against.
- **Human takes are test-only** (`split: "test"` in every imported label), and
  disagreements between annotators are reported in `qc/agreement.md`, never
  averaged away.

## Preconditions

```bash
make setup        # .venv with the pinned pip deps
make setup-mfa    # the separate `mfa` conda env, plus english_us_arpa models
ffmpeg -version   # only needed as a decode fallback (build_clean reads mp3/ogg
                  # through libsndfile; ffmpeg is the third decoder it tries)
```

`make check-env` verifies all three.
